# Tinycast extensions

Independent Raycast-compatible extensions for Tinycast. Each extension owns its manifest, source,
build, and installation instructions; build and install them separately.

| Extension | Purpose | Source |
| --- | --- | --- |
| Screenshot Manager | Browse, search, and paste screenshots | [`extensions/screenshot-manager`](extensions/screenshot-manager/) |
| Grammar | Generate Pi or Codex alternatives for clipboard text | [`extensions/grammar`](extensions/grammar/) |

Install a built extension in Tinycast under **Settings → Extensions → Install → Local folder** and
select that extension's directory.
